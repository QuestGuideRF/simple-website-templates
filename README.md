# Simple Website Templates

Коллекция простых и чистых HTML/CSS шаблонов для создания веб-сайтов. Все шаблоны готовы к использованию и легко настраиваются.

## Описание

Набор минималистичных веб-шаблонов, созданных с использованием чистого HTML и CSS. Каждый шаблон имеет свой уникальный стиль и может быть использован как основа для создания персонального или коммерческого сайта.

## ✨ Особенности

- Простые и чистые дизайны
- Легкая настройка и кастомизация
- Готовые к использованию шаблоны
- Минималистичный подход
- Различные стили оформления

## 🚀 Быстрый старт

1. Выберите нужный шаблон из коллекции
2. Откройте файл `index.html` в браузере
3. Или используйте локальный веб-сервер:
   ```bash
   python -m http.server 8000
   ```

## 🛠 Использование

### Доступные шаблоны

Коллекция включает следующие варианты:

1. **Simple Single Page v1** - Простая одностраничная версия
2. **Simple Single Page with Banner v1** - Одностраничная с баннером
3. **Sky Style v1** - Стиль "небо"
4. **Folder Style v1** - Стиль "папка"
5. **With Banner v1, v2, v3** - Различные варианты с баннером

### Настройка шаблона

1. Откройте HTML файл выбранного шаблона
2. Измените текстовый контент
3. Замените изображения на свои
4. Настройте стили в CSS файле (если применимо)
